# App prototype source

Source of the [app prototype](https://claude.ai/artifact/YJRK2QzMdDdm4c4DQhwWZq). It is a throwaway reference for M1.3, M2.1, M2.4, and M2.5, not production code.

Run `python3 build.py .` in this folder to build `astra-app.html`, which inlines the images in `img/`. The images are public domain, namely Hokusai's Great Wave, Raphael's School of Athens, and a NASA photograph of Saturn.
