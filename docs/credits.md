# Credits

## Fonts

The web app serves these fonts itself from `apps/web/public/fonts/`, so student browsers make no call to a font service. Both fonts use the SIL Open Font License 1.1, and the license text sits beside the font files.

| Font | Used for | Copyright | License file |
| --- | --- | --- | --- |
| [Barlow](https://github.com/jpt/barlow) | The interface | Copyright 2017 The Barlow Project Authors | `apps/web/public/fonts/OFL-Barlow.txt` |
| [Newsreader](https://github.com/productiontype/Newsreader) | The tutor's words and the home greeting | Copyright 2020 The Newsreader Project Authors | `apps/web/public/fonts/OFL-Newsreader.txt` |

The board adds two more, both served by us. KaTeX's math fonts come with the `katex` package, version 0.19.1, under its MIT license, which is at `apps/web/public/fonts/LICENSE-KaTeX.txt`, and the browser fetches only those an equation uses. The handwriting is EMS Tech, a single-line font by Sheldon B. Michaels, converted to SVG by Windell H. Oskay, derived from Architects Daughter by Kimberly Geswein, under the SIL Open Font License 1.1. Its strokes are data in `packages/board/src/ink/stroke-font-data.ts`, generated by `packages/board/scripts/build-stroke-font.mjs` from `EMSTech.svg` in the `hersheytext` package, version 2.0.0, and its license is at `apps/web/public/fonts/OFL-EMS-Tech.txt`.

The files come from the `@fontsource/barlow` and `@fontsource-variable/newsreader` packages, version 5.3.0. We ship the Latin, Latin Extended, and Vietnamese subsets. The Vietnamese subset also holds letters that Yoruba and Igbo names use, such as Ọ and Ẹ. A browser downloads a subset when the page uses a character in that subset's `unicode-range`. Neither font has Ṣ, ṣ, Ṅ, ṅ, Ǹ, or ǹ. The Latin Extended range still lists them, so a name with one of these letters downloads that file, finds no such letter in it, and shows the letter in a system font.

## Our own drawings

We made these drawings for this product.

- `apps/web/src/home/drawings.tsx` holds `arc`, `forces`, `growth`, and `helix`.
- `apps/web/src/home/interestDrawings.tsx` holds a drawing for each of the 12 interest chips: `basketball`, `football`, `movies`, `gaming`, `music`, `art`, `space`, `cars`, `cooking`, `fashion`, `coding`, and `history`. No team, brand, or game appears in them.
- `apps/web/src/ui/dots/planetDots.ts` and `apps/web/src/ui/dots/chartBackdrop.ts` draw the planet and the star chart on sign-in and onboarding.
- `apps/web/src/home/lineDrawings.tsx` holds `balance`, `bars`, `binary`, `braking`, `branches`, `circuit`, `clock`, `curve`, `frames`, `grid`, `lock`, `parabola`, `piston`, `pitch`, `prism`, `route`, `string`, `table`, `tangent`, `terrain`, `triangle`, and `waveform`.
