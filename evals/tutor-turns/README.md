# Tutor turns

Scripted lessons that run against any model by name and any prompt version. They measure speed, tokens, cost, and what code can check on every reply, and they save each transcript for a person to read. `pnpm eval:tutor --dry-run` loads them and spends nothing.

- `turns-30.json` is a lesson of 30 student messages, about 10 minutes at 3 turns a minute.
- `turns-90.json` is three lessons in one session, 90 messages, about 30 minutes.
- `safety-wordings.json` is one wording a row, each with what it expects: help, a lesson, a calm decline, a doctor, and so on. `docs/tests/safety.md` says how to run it.
- `safety-context.json` holds the same words with fixed lines before them, each row saying whether it should stay quiet, fire, or read as clear danger, read by `eval:safety-check`.
- `groups-safety.json`, `groups-math.json`, and `groups-teaching.json` are short groups of messages, each group in a session of its own, run by `eval:groups` and read by a person. A failed check exits non-zero. `--prompt v1` runs the prompt from before M3.8, so a teaching case can be seen failing. `--repeat` and `--min-share` hold a case to a share of its runs, because one reply is one sample. A safety check must pass every run.
- `groups-board.json` holds work on the shared board, with tasks, marks, and what code decided, run by `pnpm eval:board`. A turn with `work` puts that work on the board the way the page does. `pnpm --filter @astra/agent eval:ink` reads back a table of handwritten lines.
- `groups-board-asks.json` holds plain asks for a table or a timeline, and `groups-board-refusals.json` holds asks past what the board can hold. Run each with `--repeat 3 --transcript <file>`, and read the file with `tally-board-lessons.ts`, which counts a claim with nothing drawn.
- `spoken-lines.json` holds lines said aloud, with what Muse really wrote for each, read by `pnpm --filter @astra/agent eval:spoken`.
- `groups-switch.json` holds a student changing the subject mid-task and coming back, run by `pnpm --filter @astra/agent eval:switch`.
- `groups-lessons.json` holds the shape of a lesson: a direct question goes hands-on, a topic teaches first and then picks an exercise, the student can overrule either, a switch renames the session, and crisis words stop all of it. Run by `pnpm --filter @astra/agent eval:kinds`. Add `--planner fail` or `--planner off` to run the same turns with no plan.
- `plan-table.json` holds what the quick planner must decide from one message, run by `pnpm --filter @astra/agent eval:plans`, which also replays `turns-30.json` for what planning costs a session.
- `groups-safety.json` and `groups-math.json` are short groups of messages, each group in a session of its own, run by `eval:groups` and read by a person. A failed check exits non-zero.
- `groups-memory.json` holds a returning student, a student with nothing remembered, stale and wrong notes, two students who must not cross, and commands written into memory, run by `pnpm --filter @astra/agent eval:groups --file memory`. Its notes reach the tutor past the screens that normally read them, so a pass proves the model holds even if the screens fail.
- `record-sessions.json` holds recorded sessions and what may be kept of each, run on the real extraction model by `pnpm --filter @astra/agent eval:record`. `results/record-replies.json` is one saved run, which `extraction.test.ts` reads, so the tests spend nothing.
- `groups-personal.json` holds one question for students who differ: interests that fit and interests that do not, a skill they showed, a struggle to pick up, a false claim in their own hobby, crisis lines with an interest on file, and commands stored as interests. Run it with `pnpm --filter @astra/agent eval:groups --file personal --prompt v2` to see the prompt before M4.2 fail, and with no `--prompt` for the prompt now.
- `lessons-personal.json` holds three students on one question, run by `eval:lessons --file lessons-personal`. `lessons/personal-before/` is the prompt before M4.2, and `lessons/personal-after/` is the prompt now.
- `lessons.json` holds whole lessons, each a student described in a few lines. `eval:lessons` plays the student with a cheap model, so the student answers what the tutor really said, and writes each lesson to `lessons/<label>/` for a person to read. `lessons/before/` is the prompt before M3.8, and `lessons/after/` is the prompt now.

Each row has the student's `text`, and may name a `check`. `apps/agent/src/tutor/eval/reply-checks.ts` holds what each name means. `REPLY_CHECKS` are patterns, and `JUDGED_CHECKS` are yes or no questions put to a second model, for what no pattern can see, such as whether a question feels like a test. `run-eval.ts` and `run-groups.ts` beside it run them. `results/` holds the runs recorded in `docs/tests/tutor-model.md`.
